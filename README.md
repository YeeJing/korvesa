# Korvesa

Korvesa is a low-altitude economy site built with Vinext, React, and Next.js.

## Requirements

- Node.js `>=22.13.0`

## Commands

```bash
npm install
npm run dev
npm test
npm run build
```

## Project Structure

- `app/`: page, layout, and UI components
- `public/`: site assets
- `tests/`: rendered HTML tests
